Cómo leer este resultado

El margen de contribución es el precio de venta menos el costo variable. Cuando es positivo, aporta primero a cubrir los costos fijos; al cubrirlos, las ventas adicionales generan utilidad.

Margen de contribución positivo

Con el precio actualizado de $6.500.000, cada unidad aporta $1.095.800 para cubrir costos fijos. El equilibrio se alcanza al vender 2,46 unidades; en unidades completas, se requieren 3 ventas.
